
Este programa en C++ valida la seguridad de una contraseña. Cuando el usuario la escribe, el programa revisa si cumple varias condiciones básicas:

Tiene al menos 8 caracteres
Tiene al menos una letra mayúscula
Tiene al menos un número
Tiene al menos un carácter especial como !, @, #, $, %, &, *
Luego suma cuántas de estas condiciones se cumplen. Según ese total, la contraseña se clasifica como:

DÉBIL: si cumple 2 o menos condiciones
MEDIA: si cumple 3 condiciones
FUERTE: si cumple las 4 condiciones
El objetivo del código es demostrar cómo usar variables booleanas, bucles, condicionales y validación de texto en C++.
